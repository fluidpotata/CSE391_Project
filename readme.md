# Best Rooms – Sublet Management System 
## Tech Stack:
Flask, Sqlite, HTML, CSS, Javascript

## Installation:
1. Clone the github repo:
 ```git clone https://github.com/fluidpotata/CSE391_Project.git```

2. Install [Python from official source](https://www.python.org/downloads/release/python-3106/)
3. Install dependecies:
 ```pip install -r requirements.txt```
4. Run the flask server:
 ```flask run```
5. The app should be running in http://localhost:5000/

## Features:
- Login system
- New Tenant Registration system
- Tenants have their dashboard where they can see their details
- Tenants can create tickets if they face issues
- Tenants can see number of unresolved tickets they have
- Tenants can see their bill status from dashboard
- Tenants can update their bill status
- Managers have their dashboard where they can see info at a glance
- Managers can create new bill sessions
- Managers can see new applicants
- Managers can approve new applicants
- Managers can add new rooms
- Managers can update different bills for a certain tenant
